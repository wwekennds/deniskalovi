– Чем TextBox отличается от TextBlock и PasswordBox?
Ответ: TextBox это поле для ввода данных, PasswordBox поле для ввода паролей (когда вводишь в него символы они блюрятся жирной точкой), TextBlock поле для вывода данных

– Почему свойство IsChecked сравнивают со значением true, а не приводят напрямую к типу bool?
Ответ: потому что оно возвращает true и название говорит само за себя, проверяет выбран он или нет

– Как сгруппировать переключатели и что произойдёт без группировки?
Ответ: сгруппировать переключатели можно через GroupBox. если не сгруппировать, то все переключатели на форме будут принадлежать ондой группе и из всех них можно будет выбрать только один

– Как получить текст выбранного элемента ComboBox?
Ответ: прописать GroupSelect.SelectedItem as ComboBoxItem)?.Content.ToString()

– Какие свойства задают диапазон и шаг ползунка?
Ответ: Minimum, Maximum, TickFrequency (шаг)

– Для чего нужен элемент GroupBox?
Ответ: для группировки переключателей и других подобных элементов
